### **Задача: Мини-платформа управления файлами**

Создай мини-приложение, состоящее из **frontend + backend + S3(minio)**, для загрузки, отображения и удаления файлов.

Используй **монорепозиторий** с общей логикой и типами между фронтом и бэком.

### **Что нужно реализовать:**

#### **Backend (/apps/api)**

- Fastify + tRPC
- Эндпоинты:
  - uploadFile(name, file) → сохраняет в **S3**
  - getFiles() → список файлов из БД
  - deleteFile(id) → удаляет файл из S3
- Храни файл метаданных (имя, URL, дата) в **PostgreSQL** через **Prisma**
- Реализуй Zod валидацию
- Типизируй все запросы/ответы (end-to-end через tRPC)
- Подключи **Kafka** для публикации события "file_uploaded" после загрузки файла

#### **Frontend (/apps/web)**

- Next.js + React + Tailwind
- UI: список файлов, кнопка загрузки(мультизагрузка/прогресс), удаление
- Используй **tRPC client** для вызова API
- Используй компоненты из /packages/ui
- Tailwind компоненты должны быть читаемыми и доступными

#### **Дополнительно (по желанию, но +++++)**

- Загрузка нескольких файлов одновременно
- Прогресс загрузки
- Простой лог в консоли, что Kafka сообщение было отправлено
- Использование docker-compose для поднятия окружения (Postgres, S3-minio, Kafka)
- Создать Job который будет вычитывать в S3 список файлов, и проверять наличие их в БД, если файла нет в БД - необходимо его удалить с S3
